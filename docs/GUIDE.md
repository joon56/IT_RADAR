# 📡 IT RADAR 이용 가이드

> <https://joon56.github.io/IT_RADAR/> · 데이터는 **매주 월·수·금** 자동 업데이트 (KST)

IT 공모전·해커톤·부트캠프·컨퍼런스·동아리 일정을 한 곳에서 추적하는 웹입니다. 회원가입 없음, 무료, 개인 설정은 전부 내 브라우저에만 저장됩니다.

---

## 1. 활동 마크 읽는 법

모든 화면이 같은 마킹 체계를 씁니다. 이것만 알면 끝.

### 기간 마크 — "이 활동 지금 어떤 상태?"

| 마크 | 의미 |
|:---|:---|
| 🟢 **신청 중** | 지금 참가 신청을 받는 기간 (마감일 있음) |
| 🟢 **진행중 (참가 가능)** | Kaggle처럼 신청/진행 경계가 없는 활동 — 지금 바로 참여 가능 |
| 🔵 **접수 예정** | 올해 열릴 예정이지만 접수 미시작 |
| 🟡 **진행중 (참가 불가)** | 진행 중이지만 신청이 이미 마감됨 |
| ⚫ **종료** | 완전히 끝남 (기록용으로 보존) |

### 시점 마크 — 캘린더·타임라인에 찍히는 날짜

| 색 | 마크 | 의미 |
|:---:|:---|:---|
| 🟢 | 신청 시작 | 접수/등록이 열리는 날 |
| 🔴 | 신청 마감 | 접수 마감일 — 가장 중요한 날짜 |
| 🔵 | 대회 시작 | 실제 대회·활동이 시작되는 날 (라운드·본선 포함) |
| 🟠 | 부분 제출 마감 | 중간 제출물(요약본·코드 등) 마감 |
| ⚪ | 활동 종료 | 완전 종료 시점 |
| 🟣 | 발표 | 결과 발표 예정일 |

## 2. 탭별 사용법

### 📅 캘린더

- 날짜 칸의 색 칩 = 그날의 시점 마크 (칩에 활동명 표시, 마우스 올리면 상세)
- **날짜 클릭** → 아래 패널에 3가지 표시:
  - **이 날의 일정** — 그날 찍힌 시점 마크들
  - **이 날 신청 중** — 신청 기간이 그 날짜에 걸친 활동
  - **이 날 진행중** — 대회 기간이 걸친 활동 (🟢 참가 가능 / 🟡 참가 불가 구분)
- 상단 버튼으로 **캘린더 구독** 가능 (아래 4번 참고)
- 단축키: `←` `→` 월 이동, `T` 오늘로

### 📊 타임라인

- 이번 달부터 6개월을 한눈에 — 🟩 신청 중 기간, 🟦 대회 진행 기간, 🔴◆ 신청 마감, 🟠◆ 부분 제출 마감
- 파란 세로선 = 오늘. **막대가 세로선 오른쪽에서 시작하면 아직 기회가 있다는 뜻**
- 모바일은 좌우로 스와이프

### 📋 목록

- 활동명 클릭 = 공식 사이트로 바로 이동
- **필터**: 상태 칩(신청 중/예정/...) + 분야 칩(AI/부트캠프/보안/...) + 검색창 (한/영 모두 검색됨)
- **D-day 배지**: 3일 이내 빨강, 7일 이내 노랑
- **☆ 별표** = 내 활동으로 저장 (아래 3번)
- **준비 체크리스트**: 주요 활동 카드의 접이식 체크박스 — 체크 상태 저장됨
- **관련 자료**: 카드마다 구글 후기·Velog·YouTube 검색 바로가기

### 🧭 로드맵

- 목표별 추천 경로 6종 (삼성 취업 / AI 연구자 / 웹 개발자 / 첫 대외활동 / 의료 AI / 글로벌 빅테크)
- 제목 클릭 → 단계 펼침. 각 단계는 실제 활동과 연결돼 상태·D-day가 실시간 표시

### 📰 브리핑

- 데이터가 갱신될 때마다 자동 생성되는 요약: 🆕 신규 / 🔄 변경 / 🔴 10일 내 마감
- "지난번 이후 뭐가 바뀌었지?"는 이 탭만 보면 됨
- **RSS 구독** 버튼으로 리더 앱에서 받아보기 가능

## 3. 개인화 기능 (내 브라우저에만 저장)

| 기능 | 방법 | 참고 |
|:---|:---|:---|
| ⭐ 내 활동 | 카드의 ☆ 클릭 | 상단에 "내 활동 D-day" 모음 생성, 목록에 "⭐ 내 활동" 필터 |
| ✅ 체크리스트 | 카드에서 "준비 체크리스트" 펼치고 체크 | 진행률 (2/4) 표시 |
| 🆕 NEW 배지 | 자동 | 내가 마지막 방문한 이후 추가된 활동에 표시 |
| 🌐 KR/EN | 우측 상단 토글 | 선택 기억됨 |

⚠️ 저장은 **기기·브라우저별**입니다. 폰과 PC는 따로 저장되고, 브라우저 데이터를 삭제하면 사라집니다. 서버에 전송되지 않으므로 다른 사람에게 보이지 않습니다.

## 4. 캘린더 구독 — 마감을 폰 알림으로

캘린더 탭 상단 버튼:

- **Google 캘린더 구독**: 클릭 → 구글 캘린더에서 "추가" 확인. 이후 데이터가 갱신되면 자동 반영
- **Apple·Outlook 구독**: 클릭하면 기본 캘린더 앱이 구독 확인창을 띄움
- **ICS URL 복사**: 다른 캘린더 앱에 직접 붙여넣기용
- **내 활동 .ics 다운로드**: 별표한 활동의 일정만 담은 파일 (일회성, 자동 갱신 안 됨)

구독해두면 신청 마감·대회 시작이 내 캘린더에 떠서 **웹을 안 열어도 알림**을 받습니다.

## 6. FAQ

**Q. 활동을 추가해달라고 요청할 수 있나요?**
네 — 위 제보 채널로 활동명과 공식 링크를 보내주세요.

**Q. 종료된 활동은 왜 남아 있나요?**
연례 대회의 내년 일정을 예측하는 기록으로 씁니다. "⚫ 종료" 필터로 걸러 보세요.

**Q. "예상"이라고 적힌 일정은 뭔가요?**
공식 발표 전, 과거 회차 패턴으로 추정한 시기입니다. 확정 날짜만 캘린더에 찍힙니다.

**Q. 특정 필터 화면을 공유하고 싶어요.**
필터를 건 상태의 주소(URL)를 그대로 복사해 보내면 같은 화면이 열립니다.
